How to transcribe (read once)
  • Write exactly what is heard, both people, in the order spoken. Don't fix grammar or summarise.
  • Use Telugu script. English words spoken in the call stay in Telugu script, the way the draft writes them: ఓకే, ఆన్లైన్, ప్లాన్.
  • Write numbers, prices, dates and names as spoken, carefully. These matter most: రెండు వేల ఐదు వందలు, not 2500.
  • If a word can't be made out, write [అస్పష్టం] in its place. If the whole clip is noise or silence, press Can't hear.
  • If the clip isn't Telugu at all, press Not Telugu.
  • Press Draft is correct only if the draft matches word for word. Otherwise edit the box and press Save correction.
  • About one clip in five is listen-only: no draft is shown, so type it from scratch. These keep the test fair, so please don't skip them.
